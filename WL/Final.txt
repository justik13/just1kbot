Вот пошаговый, структурированный гайт по развертыванию связки **VLESS XHTTP + Padding через Yandex Cloud CDN** с двухсерверным каскадом, адаптированный под **AmneziaVPN** и интеграцию через библиотеку **`amnezia-api`**.

Гайд полностью очищен от блоков кода и содержит логику, параметры, порядок действий и правила сборки.

---

## 🏗 Архитектура системы

Трафик проходит через следующий маршрут:

* **Приложение AmneziaVPN** посылает HTTP/2-запросы с методом **OPTIONS** и обфускацией (Padding).


* **Yandex Cloud CDN** принимает трафик, скрывает IP-адрес Origin-сервера и маскирует подключение.


* **Origin-сервер (Россия)** принимает SSL-трафик на Nginx, подменяет метод **OPTIONS на POST**, отключает буферизацию и передает пакеты в локальный инбаунд Xray.


* **Exit-сервер (Зарубежье)** получает чистый VLESS-Vision трафик с Origin-сервера по защищенному порту 10443 и выходит в свободный интернет.

## 🌐 Шаг 1. Настройка DNS

В панели DNS домена создайте записи без внешнего проксирования (в режиме DNS Only):

* **Запись A (`origin`)**: Указывает на IP-адрес Origin-сервера в РФ.


* **Запись A (`relay`)**: Указывает на IP-адрес Exit-сервера за рубежом.


* **Запись CNAME (`cdn`)**: Указывает на адрес CDN-ресурса Яндекса (получите в Шаге 4).


* **Запись CNAME (`_acme-challenge.cdn`)**: Для проверки прав на выпуск SSL-сертификата в Yandex Cloud.



---

## 🛡 Шаг 2. Настройка Exit-сервера (Зарубежье)

1. **Выпуск SSL-сертификата:** Получите сертификат Let's Encrypt через Certbot для Exit-домена.


2. **Конфигурация Xray Inbound:**
* Протокол: **VLESS** с потоком **xtls-rprx-vision**.


* Порт: **10443**.


* Транспорт: **TCP + TLS**.


* Значение ALPN: **h2** и **http/1.1**.


* Пути к сертификату: Укажите выданные файлы SSL.




3. **Конфигурация Xray Outbound:**
* Протокол: **freedom** (прямой выход в сеть).




4. **Безопасность:** Ограничьте входящий доступ на порт **10443** через фаервол (UFW/iptables), разрешив подключения **строго с IP-адреса Origin-сервера**.



---

## 🇷🇺 Шаг 3. Настройка Origin-сервера (Россия)

1. **Выпуск SSL-сертификата:** Выпустите Let's Encrypt сертификат для Origin-домена.


2. **Конфигурация Xray:**
* **Inbound:** Протокол **VLESS**, транспорт **XHTTP**, слушает адрес **127.0.0.1 на порту 8003**. В настройках XHTTP укажите режим **packet-up**, ваш секретный путь, включите режим обфускации **xPaddingObfsMode**, ключ **dc**, заголовок **X-Cache**, метод **tokenish** и размещение **queryInHeader**.


* **Outbound:** Протокол **VLESS-Vision + TLS**, подключается на Exit IP и порт **10443**, указав SNI Exit-домена.




3. **Конфигурация Nginx:**
* **Маппинг методов:** Создайте карту преобразования, которая перенаправляет запросы с HTTP-методом **OPTIONS в метод POST** для внутренних прокси-запросов.


* **Настройки хоста:** Слушает порт 443 (SSL) для Origin-домена.


* **Параметры прокси:** Проксирует путь XHTTP на **[http://127.0.0.1:8003](http://127.0.0.1:8003)**.


* **Оптимизация:** Обязательно отключите буферизацию (параметры **proxy_buffering off** и **proxy_request_buffering off**), а также выставите таймауты чтения и передачи на 3600 секунд.





---

## ☁️ Шаг 4. Настройка Yandex Cloud CDN

1. **Certificate Manager:**
* Добавьте сертификат Let's Encrypt для CDN-домена.


* Пройдите проверку прав через CNAME-запись в DNS и дождитесь статуса «Выпущен».




2. **Группа источников CDN:**
* Тип источника: **Сервер**.


* Домен источника: **Origin-домен** (указывается доменное имя, а не IP).




3. **CDN-ресурс:**
* Доменное имя: **CDN-домен**.


* Протокол источников: **HTTPS** (порт 443).


* Заголовок Host и SNI-хост: Установите свое значение ➡️ **Origin-домен**.


* Сертификат: Выберите выданный сертификат из Certificate Manager.


* Редирект: Включите перенаправление с HTTP на HTTPS.


* Кеширование: Полностью отключите кеширование на CDN и в браузере.


* Разрешенные методы: Выберите **GET, HEAD, OPTIONS**.




4. **Привязка DNS:** Скопируйте имя CDN-ресурса (вида *.yccdn.ru) и привяжите его как CNAME-запись для CDN-домена.

## ⚡️ Шаг 5. Принцип сборки ключей через `amnezia-api`

При формировании ключей для AmneziaVPN через библиотеку `amnezia-api` необходимо передавать конфигурацию в формате контейнера Amnezia.

### Структура объекта подключения:

1. **Обёртка контейнера Amnezia:**
* Выбирается тип контейнера: **`amnezia-xray`**.


* Устанавливается флаг стороннего конфига: **`isThirdPartyConfig = True`**.


* В поле **`last_config`** помещается отформатированная строка JSON-конфигурации Xray.


* Поле **`hostName`** задает CDN-домен.


* Поле **`defaultContainer`** задает значение **`amnezia-xray`**.




2. **Вложенная конфигурация Xray (`last_config`):**
* **Inbounds:** Входящий локальный SOCKS-прокси на 127.0.0.1:10808 с поддержкой UDP.


* **Outbounds:**
* Протокол: **`vless`**.


* Адрес: **CDN-домен**, порт **443**, шифрование **`none`**, ваш **UUID**.


* Сеть: **`xhttp`**.


* Безопасность: **`tls`**, ServerName — **CDN-домен**, ALPN — массив **`["h2"]`**.


* Настройки XHTTP:
* **`mode`**: `packet-up`.


* **`path`**: Ваш секретный путь.


* **`uplinkHTTPMethod`**: `OPTIONS`.


* **`xPaddingObfsMode`**: `True`.


* **`xPaddingKey`**: Ваш двухсимвольный ключ.


* **`xPaddingHeader`**: `X-Cache`.


* **`xPaddingMethod`**: `tokenish`.


* **`xPaddingPlacement`**: `queryInHeader`.


* Дополнительно: `scMaxBufferedPosts = 30`, `scMaxEachPostBytes = 1000000`, `scMinPostsIntervalMs = 30`.








3. **Кодирование финального ключа:**
* Сформированный общая структура контейнера Amnezia сериализуется и кодируется в формат **Base64**.


* На выходе добавляется префикс **`vpn://`**.

## 🔍 Шаг 6. Проверка и импорт

1. **Импорт в клиент:** Полученный ключ префикса `vpn://` скопируйте и вставьте в клиент **AmneziaVPN** через кнопку **«+» ➔ «Импортировать из строки»**.


2. **Диагностика сети:**
* Для проверки доступности отправите тестовый HTTP-запрос методом **OPTIONS** на эндпоинт проверки CDN.


* Успешный статус проверки: ответ **HTTP/2 204** с заголовком **X-CDN-Origin: ok**.


* В логах Nginx на Origin-сервере должны фиксироваться входящие запросы к секретному пути, транслируемые без задержек и ошибок.
