## 1. ОБЩАЯ КОНЦЕПЦИЯ И ЦЕЛИ ПРОЕКТА

Сервис **«Белый Интернет»** — выделенный продукт внутри бота `just1kbot`, обеспечивающий гарантированный доступ в глобальный интернет во время действия режима жестких белых списков ТСПУ на мобильных сетях в РФ.

* **Протокол:** VLESS XHTTP (`packet-up`, `uplinkHTTPMethod="OPTIONS"`) через Yandex Cloud CDN.
* **Основной клиент:** **INCY** (с поддержкой нативного виджета трафика и срока подписки).
* **Второстепенные клиенты:** AmneziaVPN (ключ `vpn://` с контейнером `amnezia-xray`), Happ, v2rayNG, NekoBox.
* **Управление серверами:** Единый интерактивный CLI-менеджер `just1knode`.

## 2. АРХИТЕКТУРА ИНФРАСТРУКТУРЫ (ORIGIN + MULTI-RELAY)

### 2.1. Схема прохождения трафика

```text
               ┌────────────────────────────────────────────────────────┐
               │                     Telegram Bot                       │
               │  - Раздел «⚪ Белый Интернет»                          │
               │  - Базовый тариф: 50 ГБ / 30 дней                      │
               │  - Докупка ГБ: +10 ГБ, +25 ГБ, +50 ГБ                  │
               │  - Подписочный фид INCY: /s/w/{token}                  │
               └──────────────────────────┬─────────────────────────────┘
                                          │
                   ┌──────────────────────┴──────────────────────┐
                   ▼                                             ▼
       [Amnezia Нода (AWG 2.0)]                      [Белый Интернет: Origin (РФ)]
       (just1knode install amnezia)                  (just1knode install origin)
       - amnezia-api (Fastify:8443)                  - Nginx (SSL, OPTIONS->POST)
       - Nginx + UFW                                 - Xray Inbounds (8003, 8004...)
                                                     - xray-api (FastAPI:5001 -> 8444)
                                                                 │
                                           ┌─────────────────────┴─────────────────────┐
                                           ▼ (Vision/TLS 10443)                        ▼ (Vision/TLS 10443)
                             [Relay 1: Германия (Exit)]                   [Relay 2: Нидерланды (Exit)]
                             (just1knode install relay)                   (just1knode install relay)
                             - Xray Freedom Inbound 10443                 - Xray Freedom Inbound 10443
                             - UFW: доступ строго с Origin                - UFW: доступ строго с Origin
```

---

### 2.2. Динамическая маршрутизация на несколько Relay-локаций

На Origin-сервере для каждого подключенного Relay настраивается:
1. Выделенный локальный порт Xray Inbound (например, `8003` для DE, `8004` для NL, `8005` для US).
2. Выделенный секретный путь в Nginx (например, `/w_9a1f2b/de`, `/w_9a1f2b/nl`).
3. Outbound-маршрут в Xray на соответствующий зарубежный Relay через VLESS-Vision TLS.

Пользователь при скачивании подписки в приложении **INCY** получает единый профиль, внутри которого сразу отображаются все активные локации с флагами стран:
* `🇩🇪 Германия (Белый Интернет)`
* `🇳🇱 Нидерланды (Белый Интернет)`
* `🇸🇪 Швеция (Белый Интернет)`

## 3. ИНТЕРАКТИВНЫЙ СЕРВЕРНЫЙ МЕНЕДЖЕР `JUST1KNODE`

### 3.1. Главное меню утилиты

Утилита развертывается на целевом сервере одной командой:
```bash
curl -sSL https://raw.githubusercontent.com/justik13/just1kbot/main/scripts/just1knode.sh -o /usr/local/bin/just1knode && chmod +x /usr/local/bin/just1knode
```

При запуске без аргументов (`sudo just1knode`) открывается интерактивное меню:

```text
┌─────────────────────────────────────────────────────────────┐
│                 🚀 JUST1KNODE CONTROL PANEL                 │
│              Менеджер серверных узлов Just1kBot             │
└─────────────────────────────────────────────────────────────┘

  [1] 🚀 Установить Amnezia API узел (AmneziaWG 2.0 для обычной подписки)
  [2] 🌐 Установить Origin узел (Белый Интернет — Входной шлюз в РФ)
  [3] 🛡️  Установить Relay узел (Белый Интернет — Зарубежный выход)
  [4] 🔄 Управление Relay-узлами на Origin (Добавить / Удалить / Список)
  [5] 📊 Статус узла и активные клиенты
  [6] 🩺 Комплексная самодиагностика (Doctor: DNS, SSL, Xray, UFW)
  [7] 🔄 Обновление ядра Xray-core
  [0] ❌ Выход

Выберите действие [0-7]: 
```

### 3.2. Сценарий `[1]`: Установка Amnezia API узла (AWG 2.0)

Предназначен для развертывания стандартных серверов под базовые тарифы AmneziaWG 2.0.

**Интерактивные шаги:**
1. Проверка окружения (Ubuntu 22.04 / 24.04).
2. Запрос доменного имени ноды (например: `api.node1.example.com`).
3. Запрос Email для выпуска SSL Let's Encrypt через Certbot.
4. Клонирование репозитория `https://github.com/kyoresuas/amnezia-api`.
5. Автоматическая генерация 32-байтного `FASTIFY_API_KEY`.
6. Настройка Nginx reverse proxy на порт `8443` с SSL-сертификатом.
7. Настройка UFW: открытие портов 22 (SSH) и 8443 (API).
8. **Итог:** Вывод готовой карточки для добавления сервера в Telegram-боте (`/admin` ➔ «Добавить сервер»).

### 3.3. Сценарий `[2]`: Установка Origin узла (Белый Интернет — Шлюз в РФ)

Развертывает входной шлюз в РФ, принимающий трафик от Yandex Cloud CDN.

**Интерактивные шаги:**
1. Запрос домена Origin (например: `origin.example.com`).
2. Запрос Email для Let's Encrypt.
3. Генерация случайного секретного базового пути XHTTP (например: `/w_7f3b8c`).
4. Генерация API-ключа для связи с ботом.
5. Установка Nginx, Xray-core (с проверкой SHA-256) и демона `xray-api`.
6. Выпуск SSL-сертификата для Origin-домена.
7. Настройка Nginx:
   - Маппинг `OPTIONS ➔ POST`.
   - `proxy_buffering off; proxy_request_buffering off;`.
   - Буферы заголовков `64k` / `128k`.
   - Проксирование API-агента на порт `8444`.
8. Настройка UFW: порты 22, 80, 443 и 8444.
9. **Итог:** Вывод параметров подключения Origin в боте.

### 3.4. Сценарий `[3]`: Установка Relay узла (Белый Интернет — Выход)

Развертывает зарубежную ноду выхода в интернет (Германия, Нидерланды и др.).

**Интерактивные шаги:**
1. Запрос порта входящего туннеля (по умолчанию `10443`).
2. Запрос IP-адреса Origin-сервера в РФ.
3. Установка Xray-core.
4. Генерация ключей VLESS-Vision TLS / Reality.
5. Настройка Inbound на порту 10443 и Outbound Freedom.
6. Настройка UFW: **порт 10443 открывается строго для IP Origin-сервера**.
7. **Итог:** Вывод команды для мгновенного добавления релея на Origin.

### 3.5. Сценарий `[4]`: Управление Relay-нодами на Origin

Позволяет администратору прямо из меню Origin-сервера управлять локациями:
* **Добавить Relay:** Ввод имени (например, `Германия`), IP-адреса релея, порта и ключа. Скрипт сам выделяет порт (8003, 8004...), добавляет Inbound/Outbound в Xray, добавляет location в Nginx и перезагружает службы.
* **Удалить Relay:** Выбор релея из списка и его корректное удаление без остановки остальных локаций.
* **Список Relay:** Вывод таблицы активных релеев с пингом и статусом доступности.

### 3.6. Сценарии `[5]`, `[6]`, `[7]`: Статус, Doctor и Обновление

* **`[5] Статус`:** Красивая сводка — статус Nginx, Xray, `xray-api`, количество активных клиентов, текущий список подключенных релеев.
* **`[6] Doctor`:** Автоматическая самодиагностика:
  - Проверка резолва DNS.
  - Срок действия SSL-сертификатов Let's Encrypt.
  - Доступность gRPC сокета Xray (`127.0.0.1:10085`).
  - Проверка соединения со всеми подключенными Relay-серверами.
  - Проверка правил фаервола UFW.
* **`[7] Обновление ядра`:** Скачивание последней проверенной версии Xray-core, тестирование конфигурации (`xray run -test`) и безопасный перезапуск.

## 4. ЛЕГКОВЕСНЫЙ СЕРВЕРНЫЙ АГЕНТ `XRAY-API` (ORIGIN)

### 4.1. Почему без 3x-ui: архитектура прямого gRPC

Агент `xray-api` представляет собой минималистичный Python-сервис (~150 строк кода на FastAPI/Uvicorn), работающий локально на порту `127.0.0.1:5001`:
* Нет веб-интерфейса, нет базы данных SQLite, нет лишних накладных расходов памяти (< 20 МБ RAM).
* Напрямую взаимодействует с локальным ядром Xray через gRPC порт `10085`:
  - `xray.app.proxyman.command.HandlerService` ➔ мгновенное добавление/удаление пользователей без перезапуска Xray.
  - `xray.app.stats.command.StatsService` ➔ точный опрос счетчиков трафика пользователей.

### 4.2. Локальная персистентность пользователей (Zero-Loss State)

Для исключения потери пользователей при перезапуске Xray или сервера:
1. При вызове `/v1/clients/sync` агент сохраняет активные UUID в локальный файл `/etc/just1knode/clients.json`.
2. При старте службы `xray-api` агент считывает `clients.json` и автоматически регистрирует всех активных клиентов в памяти Xray через gRPC.
3. **Результат:** Никаких 503 ошибок, никаких сложных epoch-токенов в БД.

### 4.3. Спецификация REST API контрактов

Агент доступен по адресу `https://origin.domain.com:8444` и защищен заголовком `X-API-Key`.

#### 1. `GET /v1/health`
Проверяет статус Xray-core и gRPC.
```json
{
  "status": "ok",
  "xray_running": true,
  "grpc_ok": true,
  "active_clients_count": 142
}
```

#### 2. `POST /v1/clients/sync`
Синхронизирует статус клиента на всех локальных Inbound-портах.
```json
// Request Body
{
  "client_id": "a2b9d4e1-73c5-4812-b964-f3e7b85a1902",
  "desired_state": "active" // "active" или "disabled"
}

// Response
{
  "status": "ok",
  "client_id": "a2b9d4e1-73c5-4812-b964-f3e7b85a1902",
  "state": "active",
  "synced_inbounds": ["inbound-de", "inbound-nl"]
}
```

#### 3. `GET /v1/traffic/snapshot`
Возвращает накопленные счетчики байтов по всем клиентам.
```json
{
  "status": "ok",
  "timestamp": 1788000000,
  "users": {
    "a2b9d4e1-73c5-4812-b964-f3e7b85a1902": {
      "uplink": 1048576,
      "downlink": 52428800
    }
  }
}
```

## 5. ЗАЩИТА ОТ ОБНАРУЖЕНИЯ И СКАНЕРОВ (ANTI-FINGERPRINTING)

### 5.1. Рандомизация XHTTP путей на Origin
* При установке Origin через `just1knode` генерируется случайный секретный путь (например, `/w_3a8c1d`).
* Каждая страна получает подпуть: `/w_3a8c1d/de`, `/w_3a8c1d/nl`.
* Прямое обращение сканеров к корню домена или случайным путям возвращает стандартную страницу-заглушку Nginx (HTTP 200 OK) либо 404.

### 5.2. Кастомизация префикса подписки в боте
* Префикс URL-подписки в боте задается через `.env` (`WHITE_INTERNET_SUB_PATH_PREFIX`, по умолчанию произвольный, например `/s/w/`).
* Токен пользователя генерируется криптографически (`secrets.token_urlsafe(32)`).
* Неавторизованные запросы к фиду подписки получают `404 Not Found` без служебных заголовков.

## 6. ПРОДУКТОВАЯ МОДЕЛЬ И ЛОГИКА В TELEGRAM-БОТЕ (`JUST1KBOT`)

### 6.1. Тарифная сетка и покупка трафика

1. **Базовый тариф:**
   - Название: `Белый Интернет 50 ГБ`
   - Цена: `250 ₽`
   - Срок: `30 дней`
   - Включенный трафик: `50 ГБ` (53 687 091 200 байт)
2. **Пакеты докупки трафика (Топ-апы):**
   - `+10 ГБ` — `40 ₽`
   - `+25 ГБ` — `100 ₽`
   - `+50 ГБ` — `200 ₽`
   - Купленные гигабайты моментально суммируются с текущим остатком трафика пользователя.

---

### 6.2. Выдача подписки для INCY (Primary Client)

При переходе в карточку подписки бот предоставляет кнопку:
* **«📋 Скопировать ссылку для INCY»** (с нативным Telegram `CopyTextButton`).
* При переходе по ссылке подписки `/s/w/{token}` сервер отдает:
  - Заголовок `Subscription-Userinfo` с точными данными (использовано / всего 50 ГБ / срок).
  - Заголовок `Profile-Title: base64:...` с названием `Белый Интернет (Just1k)`.
  - Base64-тело со списком всех активных Relay-серверов.
* Пользователь вставляет ссылку в приложение INCY в 1 клик и сразу видит все страны и виджет трафика.

---

### 6.3. Выдача ключей для AmneziaVPN и других клиентов

* Для пользователей AmneziaVPN доступна кнопка **«🔑 Ключ для AmneziaVPN»** — выдает готовый ключ формата `vpn://` (контейнер `amnezia-xray`).
* Для пользователей Happ / v2rayNG / NekoBox ссылка подписки работает стандартно.

---

### 6.4. Учет трафика, автоотключение и реактивация

1. **Фоновый воркер трафика (`WhiteInternetTrafficWorker`)**:
   - Опрашивает `/v1/traffic/snapshot` на Origin-сервере.
   - Вычисляет дельту использованного трафика и списывает байты из баланса подписки.
2. **Исчерпание квоты или истечение срока:**
   - Если остаток трафика `<= 0` или `expires_at <= now()`:
     - Статус подписки переходит в `EXHAUSTED` или `EXPIRED`.
     - Бот отправляет команду на Origin: `POST /v1/clients/sync` с `desired_state: "disabled"`.
     - Пользователь получает уведомление в Telegram с кнопками докупки трафика или продления.
3. **Продление или покупка топ-апа:**
   - Трафик пополняется, статус возвращается в `ACTIVE`.
   - Бот мгновенно отправляет команду на Origin: `POST /v1/clients/sync` с `desired_state: "active"`.
   - Доступ восстанавливается автоматически без необходимости менять ссылку в клиенте.
