# Автоматическая выгрузка резервных копий в Google Drive

В Just1kBot реализована безопасная автоматическая выгрузка зашифрованных резервных копий базы данных PostgreSQL в **Google Drive** с использованием утилиты `rclone`.

Для личных аккаунтов Google (включая подписки **Google One / Google Pro**) выгрузка выполняется от имени вашего пользователя через OAuth 2.0 токен, расходуя дисковую квоту вашего личного Google-аккаунта.

---

## 🔒 Безопасность и архитектурные принципы

1. **Сквозное шифрование (End-to-End Encryption)**:
   * База данных дампится через `pg_dump`, упаковывается в `gzip` и шифруется публичным ключом `age` (`.sql.gz.age`).
   * В Google Drive выгружается **исключительно зашифрованный файл** (`.sql.gz.age`). Исходный незашифрованный файл удаляется до начала выгрузки.
   * Без вашего приватного ключа (`backup_private_key.txt`, который хранится оффлайн) расшифровать резервную копию невозможно даже при полном доступе к Google-диску.
2. **Файловая изоляция секретов в Docker**:
   * Токен авторизации и параметры Google Drive хранятся **исключительно** в конфигурационном файле `backups/rclone.conf` с правами доступа `0600`.
   * Каталог `backups/` смонтирован **только** в контейнер `just1kbot_backup`.
   * Контейнеры веб-приложения (`bot`) и миграций (`migrate`) **не имеют доступа** к `backups/` и файлу `rclone.conf`, что исключает утечку учетных данных.
   * Контейнер бэкапа работает со статусом `read_only: true` и сброшенными Linux capabilities (`cap_drop: ALL`).
3. **Безопасная ротация (Scoped Cleanup)**:
   * Бэкапы на Google Диске хранятся **14 дней** (настраивается через `GDRIVE_RETENTION_DAYS`).
   * Удаление устаревших копий выполняется строго по маске `--include "just1kbot_*.sql.gz.age"`, что исключает случайное удаление любых других файлов в вашей папке Google Диска.
4. **Контроль ошибок (Fail-Closed)**:
   * Если соединение с Google Drive или авторизация завершились с ошибкой, скрипт завершается с кодом ошибки (`exit 1`), сигнализируя планировщику cron и администратору о сбое.
   * При этом локальный зашифрованный архив **гарантированно сохраняется на диске сервера**.

## 📋 Пошаговая настройка для личного аккаунта Google (Google Pro / One)

### Шаг 1. Создание папки на Google Диске

1. Откройте [Google Drive](https://drive.google.com/).
2. Создайте папку для бэкапов (например, `Just1kBot Backups`).
3. Зайдите внутрь папки и посмотрите в адресную строку браузера:
   ```text
   https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz123456
   ```
4. Скопируйте **ID папки** — это строка символов после `/folders/` (в примере: `1AbCdEfGhIjKlMnOpQrStUvWxYz123456`).

---

### Шаг 2. Однократное получение OAuth токена (на вашем ПК)

> [!NOTE]
> В течение 2026 года Google выводит из эксплуатации общий (shared) Client ID rclone. Создание собственного Client ID в Google Cloud Console занимает 2 минуты, гарантирует отсутствие ограничений скорости и обеспечивает постоянную работу бэкапов.

1. **Создание Client ID в Google Cloud Console**:
   * Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
   * Создайте новый проект (например, `Just1kBot-Backup`).
   * Перейдите в **APIs & Services** ➔ **Enabled APIs & Services** ➔ нажмите **+ ENABLE APIS AND SERVICES**.
   * Найдите **Google Drive API** и нажмите **Enable**.
   * В левом меню откройте **OAuth consent screen** (Экран согласия OAuth):
     * User Type: выберите **External** ➔ нажмите **Create**.
     * Укажите App name (`Just1kBot`), ваш email в полях поддержки и контактов разработчика ➔ нажмите **Save and Continue**.
     * В разделе **Scopes** нажмите **Add or remove scopes**, выберите `https://www.googleapis.com/auth/drive` ➔ нажмите **Update** ➔ **Save and Continue**.
     * В разделе **Test users** нажмите **+ ADD USERS**, укажите ваш личный Google email (`@gmail.com`) ➔ нажмите **Save and Continue**.
   * **Важно! Снятие 7-дневного ограничения (Publish App)**:
     * Вернитесь на вкладку **OAuth consent screen**.
     * В блоке **Publishing status** нажмите кнопку **PUBLISH APP** (Опубликовать приложение) и подтвердите публикацию.
     * > [!IMPORTANT]
     * > Если приложение останется в статусе «Testing», Google выдает refresh token со сроком жизни **ровно 7 дней**. После нажатия **PUBLISH APP** ограничение снимается, и refresh token сохраняет действие для постоянной работы бэкапов. Верификацию Google проходить не требуется, так как вы используете приложение лично.
   * В левом меню откройте **Credentials** (Учетные данные):
     * Нажмите **+ CREATE CREDENTIALS** ➔ **OAuth client ID**.
     * Application type: выберите **Desktop app** (Классическое приложение).
     * Нажмите **Create**.
     * Скопируйте полученные **Client ID** и **Client Secret**.

2. **Авторизация через rclone**:
   * Установите `rclone` на ваш компьютер (**Windows**: `winget install Rclone.Rclone`, **macOS**: `brew install rclone`, **Linux**: `sudo apt install rclone`).
   * Запустите авторизацию в терминале с вашими ключами:
     ```bash
     rclone authorize "drive" "ВАШ_CLIENT_ID" "ВАШ_CLIENT_SECRET"
     ```
   * В браузере откроется окно авторизации Google ➔ войдите под своим Google Pro / One аккаунтом и нажмите **«Продолжить» / «Разрешить» (Allow)**.
   * В терминале появится строка токена в формате JSON:
     ```json
     {"access_token":"ya29.a0...","token_type":"Bearer","refresh_token":"1//04...","expiry":"..."}
     ```
     Скопируйте этот JSON-токен целиком (вместе с фигурными скобками).

### Шаг 3. Интерактивная настройка через `just1kbot` (Мастер-опросник)

Все действия на сервере выполняются штатно через утилиту `just1kbot` без ручной правки конфигов:

1. На сервере выполните команду:
   ```bash
   just1kbot gdrive
   ```
   *(Либо запустите `just1kbot` ➔ выберите пункт `[4] Управление бэкапами` ➔ `[3] Настройка выгрузки в Google Drive`)*.

2. Интерактивный опросник пошагово запросит данные:
   * **Включить автоматическую выгрузку в Google Drive**: нажмите Enter (`Y`).
   * **ID целевой папки на Google Диске**: вставьте ID папки (или ссылку на нее), скопированный на Шаге 1.
   * **Client ID**: вставьте ваш Client ID из Google Cloud Console (требуется для автоматического обновления токенов).
   * **Client Secret**: вставьте ваш Client Secret (ввод скрыт для безопасности).
   * **OAuth токен**: вставьте скопированный на Шаге 2 JSON-токен (начинается с `{`, ввод скрыт).
   * **Срок хранения бэкапов на Google Диске (дней)**: укажите количество дней (по умолчанию 14).
   * **Выполнить тестовое создание и выгрузку бэкапа**: нажмите Enter (`Y`) для мгновенной валидации доступа.

3. Мастер автоматически создаст конфигурационный файл `backups/rclone.conf` с правами доступа `0600` и включит параметр `GDRIVE_BACKUP_ENABLED=true` в `.env`. Если тестовая выгрузка завершится ошибкой, мастер предложит отменить изменения (Rollback).

---

### Шаг 4. Проверка и диагностика

1. Запустите системную диагностику:
   ```bash
   just1kbot doctor
   ```
   В секции проверки бэкапов появится:
   ```text
   Google Drive бэкап: настроен (папка ID: 1AbCdEfGhIj..., конфиг: backups/rclone.conf, права: 0600) (OK)
   ```

2. Выполните ручной запуск резервного копирования:
   ```bash
   just1kbot backup
   ```
   В терминале отобразится полный цикл:
   ```text
   Создание backup...
   Шифрование backup (atomic write)...
   Загрузка encrypted backup в Google Drive (rclone)...
   Google Drive upload успешно завершён: just1kbot_20261003_120000.sql.gz.age
   Очистка устаревших бэкапов в Google Drive (старше 14 дн.)...
   Backup создан: /backups/just1kbot_20261003_120000.sql.gz.age
   ```

---

### Отключение выгрузки в Google Drive

Чтобы временно отключить выгрузку без удаления конфигурации:
1. Запустите `just1kbot gdrive`.
2. На первый вопрос ответьте `n`.
3. Параметр `GDRIVE_BACKUP_ENABLED=false` будет сохранен в `.env`, и автоматическая выгрузка в Google Drive будет отключена (бэкапы продолжат создаваться локально).

## ⏰ Расписание автоматических бэкапов

Штатный планировщик `cron` сервера настроен на ежедневный запуск резервного копирования в **02:00**:
```bash
0 2 * * * flock -n /tmp/just1kbot-backup.lock sh -c 'cd /opt/just1kbot && docker compose --profile tools run --rm backup >> /opt/just1kbot/backups/backup.log 2>&1'
```
Каждую ночь в 02:00 зашифрованная копия автоматически выгружается в Google Drive, а старые архивы старше 14 дней удаляются. Логи процесса записываются в `backups/backup.log`.
