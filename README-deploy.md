# Just1kBot Deploy Runbook

Этот документ описывает использование единого скрипта деплоя `just1kbot.sh`.

Система спроектирована для работы на Ubuntu 24.04 (один VPS).
Скрипт полностью идемпотентен, все команды управляют состоянием предсказуемо и безопасно для ваших данных.

## 1. Установка на пустой или занятый сервер

```bash
sudo ./just1kbot.sh install
```

**Что делает:**
- Устанавливает системные зависимости (PostgreSQL, Redis, Python).
- Создает пользователя `just1kbot`, базу данных `just1kbot_bot`.
- Создает `.env` файл из шаблона (если его нет).
- Размещает код в `/opt/just1kbot/releases/<timestamp>`, применяет миграции Alembic.
- Создает и запускает `just1kbot.service`.

> **Важно:** после первой установки скрипт сгенерирует `.env` файл с плейсхолдерами. Вам необходимо отредактировать `/opt/just1kbot/.env` (заполнить `BOT_TOKEN` и прочие данные) и перезапустить сервис (или выполнить `update`).

Если сервер не пустой, скрипт проверит наличие конфликтов и спросит подтверждение.

## 2. Обновление

```bash
sudo ./just1kbot.sh update
```

**Что делает:**
- Клонирует текущий код в новый релиз.
- Устанавливает зависимости в новый virtualenv.
- Применяет миграции базы данных.
- Переключает симлинк `current`.
- Перезапускает сервис.

В случае ошибки (например, сбой миграции) скрипт автоматически вернет симлинк на предыдущий релиз.

## 3. Откат (Rollback)

```bash
sudo ./just1kbot.sh rollback
```

**Что делает:**
- Переключает `current` симлинк на предыдущую версию кода.
- Перезапускает сервис.
- **Внимание:** база данных автоматически не откатывается (чтобы не потерять бизнес-данные).

## 4. Бэкапы и Восстановление

### Бэкап
```bash
sudo ./just1kbot.sh backup
```
- Делает дамп базы данных `pg_dump`.
- Шифрует дамп утилитой `age` (ключ создается автоматически, если его нет).
- Сохраняет результат в `/var/lib/just1kbot/backups/`.

### Восстановление
```bash
sudo ./just1kbot.sh restore
```
- Берет самый свежий бэкап.
- Расшифровывает его.
- Останавливает бота, удаляет старую базу, создает новую и восстанавливает дамп.

## 5. Удаление и Очистка

### Полное удаление
```bash
sudo ./just1kbot.sh uninstall
```
- Останавливает и удаляет systemd-сервис.
- Удаляет код, virtualenv, конфигурации и пользователя системы.
- **Сохраняет базу данных и бэкапы.**

### Очистка остатков (Clean)
```bash
sudo ./just1kbot.sh clean
```
- Управляемая очистка ресурсов (удобно, если установка прервалась на середине). Требует подтверждения.

## 6. Диагностика

```bash
# Диагностический отчет (размер БД, статусы сервисов, пути)
sudo ./just1kbot.sh doctor

# Статус systemd-сервиса
sudo ./just1kbot.sh status

# Просмотр логов
sudo ./just1kbot.sh logs
```
