# 🧪 Руководство по симуляционному боту Just1kBot (`scripts/simulate_bot.py`)

## 📌 Назначение
`scripts/simulate_bot.py` — это изолированный, автономный стенд для локального тестирования и валидации функционала Telegram-бота **just1kbot** без необходимости разворачивать реальные серверы Amnezia VPN, подключать реальный мерчант ЮKassa или настраивать PostgreSQL и Redis.

---

## 🔒 Конфиденциальность и безопасность
- В скрипте **нет реальных секретов, паролей, ключей шифрования или личных Telegram ID** (используются исключительно безопасные локальные заглушки по умолчанию).
- Конфигурация считывается из аргументов командной строки или стандартных переменных окружения:
  - `BOT_TOKEN` или `TEST_BOT_TOKEN` — токен бота (от BotFather).
  - `ADMIN_IDS` — ID администраторов через запятую.
  - `DATABASE_URL` — строка подключения к БД (по умолчанию `:memory:`).

---

## 🚀 Быстрый запуск

### 1. Запуск с передачей токена через аргумент:
```bash
python scripts/simulate_bot.py --token 123456789:ABCDefGhIjKlMnOpQrStUvWxYz
```

### 2. Запуск с передачей токена и ID администратора:
```bash
python scripts/simulate_bot.py --token 123456789:ABCDef... --admin-id 872658825
```

### 3. Запуск через переменные окружения:
```bash
export BOT_TOKEN="123456789:ABCDef..."
export ADMIN_IDS="872658825"
python scripts/simulate_bot.py
```

### 4. Параметры командной строки:
| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--token` | `$BOT_TOKEN` / `$TEST_BOT_TOKEN` | Токен Telegram-бота |
| `--admin-id` | `$ADMIN_IDS` | Список Telegram ID администраторов (через запятую) |
| `--db-url` | `sqlite+aiosqlite:///:memory:` | URL базы данных (поддерживается как `:memory:`, так и локальный файл `sqlite+aiosqlite:///sim.db`) |
| `--seed-balance-real` | `350` | Начальный реальный баланс в рублях для нового пользователя |
| `--seed-balance-bonus` | `150` | Начальный бонусный баланс в рублях для нового пользователя |
| `--no-auto-seed` | `false` | Отключить автоматическое создание баланса, устройств и рефералов для новых пользователей |
| `--log-level` | `INFO` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`) |

## 🛠 Архитектура и эмуляция

### 1. Эмуляция PostgreSQL в SQLite
- **Advisory Locks**: функции `pg_advisory_xact_lock`, `pg_advisory_lock`, `pg_advisory_unlock` зарегистрированы на уровне `aiosqlite` и работают прозрачно.
- **Математика и типы**: зарегистрирована функция `trunc()`, эмулированы типы `JSONB`, `ARRAY`, `BIGINT`.
- **Частичные уникальные индексы**: создаются необходимые частичные индексы для поддержки предложений `ON CONFLICT (...) WHERE ... DO NOTHING` (включая `uq_paid_value_conversion_quote` и `uq_paid_value_account_purchase`).

### 2. Эмуляция Amnezia VPN API
- Генерация валидных конфигураций **AmneziaWG 2.0 (`amneziawg2`)** с реальными параметрами обфускации (`Jc`, `Jmin`, `Jmax`, `S1..S4`, `H1..H4`, `I1..I5`).
- Поддержка создания, удаления и списка профилей.
- Корректная генерация файлов `.vpn` (для AmneziaVPN) и `.conf` (для AmneziaWG / Keenetic AWG) и отправка в чат через `render_hub` и Telegram Documents.

### 3. Эмуляция ЮKassa и пополнения баланса
- Генерация тестовых счетов и платежных ссылок.
- Автоматическое подтверждение платежа при ручной проверке («Проверить оплату») с начислением средств на баланс и запуском сквозного settlement pipeline (включая реферальные бонусы).

### 4. Поддержка Telegram Message Effects (Telegram Bot API 7.4+)
В Telegram Bot API параметр `message_effect_id` ограничен 6 официальными эффектами (проверено прямым сканированием 696 ID):
- 🔥 **`EFFECT_FIRE`** (`5104841245755180586`) — при успешном создании VPN-устройства и начислении реферального бонуса.
- 🎉 **`EFFECT_CONFETTI`** (`5046509860389126442`) — при пополнении баланса, покупке, продлении и смене тарифа.
- 👍 **`EFFECT_LIKE`** (`5107584321108051014`) — при системных подтверждениях (например, успешное переименование устройства).
- ❤️ **`EFFECT_HEART`** (`5159385139981059251`) — благодарности, отзывы.
- 👎 **`EFFECT_DISLIKE`** (`5104858069142078462`) — отмена действий.
- 💩 **`EFFECT_POOP`** (`5046589136895476101`) — системные сбои / уведомления.
- Поддержка `<blockquote expandable><code>...</code></blockquote>` для ключей подключения и гайдов.
- Защита длины `CopyTextButton` (<= 256 символов).

### ⚠️ Границы эмуляции (честные ограничения)
Симулятор покрывает бизнес-логику и UI-контракты, но **не является полной заменой PostgreSQL-окружения**:
- advisory locks (`pg_advisory_xact_lock`) не эмулируются — конкурентные financial-сценарии тестируйте на Postgres (см. `tests/*_postgres.py`);
- диалект-специфика (`ON CONFLICT`, JSONB/ARRAY, partial unique indexes) имитируется частично;
- транзакционные таймауты/изоляция отличаются от продакшн-настройок.

Для release-gate используйте CI-джобу с реальным PostgreSQL + этот стенд как быстрый UX-прогон.

## 🧑‍💻 Динамический автосидинг
При первом обращении любого пользователя (отправка `/start`):
1. Создается запись пользователя в БД.
2. Начисляется баланс: **350 ₽ реального + 150 ₽ бонусного**.
3. Активируется подписка **«Семейный» (5 устройств, 30 дней)**.
4. Создается 1 активное тестовое устройство (**iPhone 16 Pro** на сервере Нидерланды).
5. Создается реферальная сеть из 3 приглашенных друзей (Дмитрий, Елена, Сергей) для полной интерактивности раздела «Реферальная программа».
