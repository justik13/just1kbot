# 📖 Справочник и архитектура текстов `just1kbot`

Этот документ описывает структуру текстовых файлов бота, правила форматирования, доступные плейсхолдеры и инструкцию по редактированию текстов.

---

## 🗂 Структура файлов текстов (`bot/texts_data/`)

| Файл | Описание и назначение | Основные разделы |
| :--- | :--- | :--- |
| **[`user_texts.py`](user_texts.py)** | Все пользовательские экраны и сообщения | Приветствие, Оплата, Подключение, Карточка устройства, Инструкции/FAQ, Поддержка, Уведомления об истечении |
| **[`referral_texts.py`](referral_texts.py)** | Реферальная программа | Экран реферальной системы, шаринг-сообщения, условия начисления бонусов |
| **[`admin_texts.py`](admin_texts.py)** | Административная панель | Дашборд, Карточки серверов, Управление пользователями, Выдача/Продление/Смена подписок, Споры, Логи аудита |
| **[`ui_texts.py`](ui_texts.py)** | Интерфейсные элементы и кнопки | Тексты inline-кнопок, бейджи статусов, навигационные подписи, короткие подсказки |
| **[`runtime_texts.py`](runtime_texts.py)** | Системные и диагностические сообщения | Сообщения очередей платежей, воркеров, детали ошибок API и системные алерты |
| **[`overrides.py`](overrides.py)** | Согласованные шаблоны и точечные переопределения | Канонические переопределения экранов главного меню, серверов и подписок |

Все тексты автоматически объединяются в модуль **[`bot/texts.py`](../texts.py)** и доступны в коде как `texts.KEY_NAME`.

## ⚙️ Правила редактирования и HTML-разметки

1. **Разрешенные HTML-теги Telegram:**
   - Жирный текст: `<b>Текст</b>`
   - Курсив: `<i>Текст</i>`
   - Моноширинный текст (для копирования): `<code>Текст</code>`
   - Многострочный блок кода: `<pre>Текст</pre>`
   - Спойлер: `<tg-spoiler>Текст</tg-spoiler>`
   - Раскрывающийся блок цитаты: `<blockquote expandable>Текст</blockquote>`
   - Ссылки: `<a href="https://...">Текст</a>`

2. **Правила использования плейсхолдеров `{var_name}`:**
   - Если в тексте указан плейсхолдер в фигурных скобках (например, `{name}`, `{valid_until}`, `{amount}`), он подставляется программой автоматически.
   - **Не удаляйте и не переименовывайте плейсхолдеры**, если обработчик ожидает их наличие.
   - Если вам нужно вывести символ фигурной скобки в тексте, экранируйте его: `{{` или `}}`.

3. **Бизнес-правила наименований (требование эквайринга/платежных систем):**
   - В текстах для пользователей **запрещено** использовать слова «VPN», «ВПН», «обход блокировок», «прокси».
   - Используйте формулировки: *«Подключение»*, *«Доступ к сервису»*, *«Устройства»*, *«Тариф»*.
   - Исключение: технические названия протокола и клиентов (`AmneziaVPN`, `AmneziaWG`, `DefaultVPN`, `.conf`, `.vpn`, `vpn://`).

## 🔍 Индекс основных плейсхолдеров по разделам

### 1. Главное меню (`HUB_HEADER`)
- `{name}` — Имя пользователя в Telegram.
- `{telegram_id}` — Telegram ID пользователя.
- `{status}` — Статус подписки (🟢 Активна / 🔴 Истекла).
- `{valid_until}` — Дата окончания подписки (например, `15.09.2026 18:30 UTC`).
- `{days_left}` — Человекочитаемый остаток (например, `14 дн.`).
- `{devices_count}` — Число активных устройств.
- `{device_limit}` — Максимальный лимит устройств по тарифу.
- `{real_balance}` — Основной баланс в рублях.
- `{bonus_balance}` — Бонусный баланс в рублях.
- `{inviter_line}` — Строка с информацией о пригласившем пользователе.

### 2. Карточка устройства (`DEVICE_MANAGE_HEADER`, `DEVICE_SHOW_KEY`)
- `{device_name}` — Название устройства.
- `{country_display}` — Флаг и название страны локации.
- `{protocol}` — Протокол (`AmneziaWG`).
- `{traffic_total}` — Общий объем переданного трафика.
- `{last_connected}` — Время последней активности.
- `{raw_config}` — Ключ подключения `vpn://...`.

### 3. Реферальный экран (`REFERRAL_TEXT_BALANCE`)
- `{referral_link}` — Персональная реферальная ссылка пользователя.
- `{invited_count}` — Количество приглашенных друзей.
- `{bonus_balance}` — Накопленный бонусный баланс.

### 4. Админка: Серверы (`ADMIN_SERVER_ADDED`, `ADMIN_SERVER_DELETE_CONFIRM`)
- `{flag}` — Эмодзи флага страны.
- `{name}` — Название сервера.
- `{protocol}` — Протокол сервера.
- `{max_clients}` — Максимальный лимит клиентов.
- `{api_url}` — API URL сервера.
- `{profiles_count}` — Количество привязанных устройств.

### 5. Админка: Подписки (`ADMIN_SUB_CONFIRM_EXTEND`, `ADMIN_SUB_CONFIRM_GRANT`, `ADMIN_SUB_TARIFF_CHANGED`)
- `{telegram_id}` — Telegram ID пользователя.
- `{tariff_name}` — Название тарифа.
- `{days_text}` — Выбранный срок продления.
- `{new_end}` — Новая дата окончания доступа.
- `{current_end}` — Текущая дата окончания доступа.
- `{devices_count}` — Число созданных устройств.
- `{device_limit}` — Лимит устройств по тарифу.

## ⚡️ Горячая перезагрузка текстов в Dev-режиме

Для обновления текстов без перезапуска процесса бота предусмотрена функция:
```python
from bot.texts import reload_texts
reload_texts()
```
При вызове этой функции все файлы из `bot/texts_data/` перезагружаются в память с валидацией ключей.
