Шаг 1. Выберите способ установки:
Внимание: Приложение Happ временно недоступно в Google Play для региона РФ, а в поиске появились небезопасные копии. Для установки из магазина используйте INCY, либо скачивайте официальный APK Happ с GitHub.
1 Установите приложение из Google Play
В Google Play доступно приложение INCY:
INCY в Google Play Официально в магазине • Доступно в РФ
Установить ↗
Для устройств без Google Play: Скачайте официальный установочный файл APK Happ напрямую с GitHub.
1 Скачайте установочный APK-файл
Нажмите кнопку скачивания APK (браузер может показать системный запрос):
Happ.apk Официальный релиз с GitHub
Скачать APK ↗
Предупреждение браузера Chrome:
1. При загрузке APK Chrome покажет: «Файл может быть опасным».
2. Нажмите «Всё равно скачать»: файл скачивается напрямую из официального репозитория разработчика на GitHub.
3. После загрузки откройте файл и выберите «Установить».
Релизы Happ Android на GitHub ↗
2 Добавьте подписку в приложение
Вернитесь на эту страницу и нажмите кнопку «Подключить в INCY» или «Подключить в Happ» вверху (приложение откроется само со списком всех серверов).
Либо нажмите «Скопировать адрес», откройте приложение, нажмите «+» и выберите «Вставить из буфера».
3 Первое подключение и подтверждение
Откройте приложение, нажмите кнопку включения и подтвердите стандартный системный «Запрос на подключение» Android (нажмите «ОК»).
В строке состояния вверху экрана появится значок ключа: соединение активно.
