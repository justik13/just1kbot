Выберите операционную систему:
1 Скачайте и установите программу
Скачайте официальный установщик Happ для Windows:
Happ для Windows (.exe) Официальный релиз с GitHub
Скачать setup.exe ↗
Если появилось окно защиты Windows (SmartScreen):
1. Нажмите ссылку «Подробнее» (More info) в окне предупреждения.
2. Появится кнопка «Выполнить в любом случае» (Run anyway): нажмите её.
3. Это стандартное системное уведомление Windows для программ, загруженных из интернета.
Официальная база знаний Happ Desktop ↗
2 Добавьте подписку
Скопируйте ссылку на подписку на этой странице. В программе Happ Desktop нажмите иконку «+» (Добавить) в левом верхнем углу и выберите «Вставить из буфера». Появится карточка подписки со списком серверов.
3 Подключение и выбор режима
Выберите локацию (например, Россия или Нидерланды) и нажмите переключатель связи. В нижней панели Happ можно выбрать режим:
• Системный прокси: перенаправляет трафик браузеров.
• TUN (Рекомендуется): направляет трафик всей системы, браузеров и приложений.
1 Скачайте и установите образ
Скачайте образ Happ для macOS (подходит для процессоров Apple Silicon M1–M4 и Intel):
Happ для macOS (.dmg) Универсальная версия (Apple Silicon / Intel)
Скачать .dmg ↗
Откройте скачанный .dmg файл и перетащите иконку программы в папку «Программы» (Applications). При первом запуске разрешите системное расширение в меню «Системные настройки → Конфиденциальность и безопасность → Разрешить».
2 Добавьте подписку
Скопируйте ссылку подписки и добавьте её в Happ через кнопку «+».
3 Включение связи
Нажмите кнопку подключения и подтвердите системный запрос macOS на добавление сетевого профиля.
1 Скачайте релиз программы
Скачайте универсальный пакет Happ Desktop для вашего дистрибутива:
Happ Desktop для Linux AppImage, deb, rpm с GitHub
Перейти к релизам ↗
Запуск AppImage в терминале:
Сделайте файл исполняемым и запустите:
chmod +x Happ-*.AppImage && ./Happ-*.AppImage
2 Добавьте подписку
Скопируйте ссылку на подписку на этой странице. В программе нажмите кнопку «+» (Добавить) и выберите «Вставить из буфера».
3 Подключение
Выберите локацию и активируйте соединение переключателем.
