# Caddy Custom Configurations (`caddy_conf.d`)

В этой директории можно размещать дополнительные конфигурационные файлы для веб-сервера Caddy с расширением `.caddy`.

Все файлы с шаблоном `*.caddy` автоматически подключаются в Caddy через директиву:
```caddy
import conf.d/*.caddy
```

- Если директория не содержит файлов `.caddy`, Caddy обслуживает только основной домен бота.
- Для подключения Uptime Kuma скопируйте `status.caddy.example` в `status.caddy` и укажите ваш домен.
